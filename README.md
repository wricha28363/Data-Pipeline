## 📌 Project Overview

This project focuses on analyzing **California traffic collision data** to understand the major factors contributing to road accidents and collision severity.

The project uses the **California Traffic Collision Data from SWITRS (Statewide Integrated Traffic Records System)** and applies **data engineering, data cleaning, exploratory data analysis (EDA), and machine learning techniques** to derive meaningful insights from the dataset.

The objective is to understand collision patterns, identify factors associated with severe collisions, and prepare the data for further machine learning and analytics use cases.
