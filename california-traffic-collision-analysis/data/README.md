# Data

This folder contains the datasets used for the **California Traffic Collision Analysis** project.

## Dataset Source

The dataset is **California Traffic Collision Data from SWITRS (Statewide Integrated Traffic Records System)**.

Source: Kaggle

https://www.kaggle.com/datasets/alexgude/california-traffic-collision-data-from-switrs

## Dataset Files

The project uses the following datasets:

### 1. Collisions
### 2. Parties
### 3. Victims
